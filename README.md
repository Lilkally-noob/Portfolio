# Lilkally | Portfolio

Personal portfolio built to showcase my frontend work and the platform behind 4D Mav's Nation.

**Live site:** https://lilkallyportfolio.vercel.app

![Portfolio preview](./public/preview.png)

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Deployed on Vercel

## Sections

- Hero
- Stats
- Featured work
- Core capabilities and tools
- Process
- Contact

## Run it locally

```bash
git clone https://github.com/Lilkally-noob/Portfolio.git
cd Portfolio 
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
